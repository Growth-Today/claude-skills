# Buying Signal Sourcer

Signal-based selling skill for B2B outbound: an orchestrator that detects, scores, and turns buying signals into warm outreach through multi-signal stacking.

| | |
|---|---|
| **What it does** | Covers the six core signals plus a 137-trigger taxonomy - job changes, funding, hiring, website visitors, company events, tech changes, competitor and content-engagement signals - with a scoring framework and executable GTM plays. |
| **Use it when** | The request is about buying signals, intent data, signal scoring, website-visitor tracking, job-change / hiring / funding / competitor signals, multi-signal stacking, tool setup (RB2B, Trigify, Common Room, Bombora), or signal-to-action playbooks. Not for general list building (use `list-builder`) or email copy (use `cold-email-writer`). |
| **Outputs** | A signal scoring framework, per-signal detection and outreach plays, tool setup guides, and signal-driven campaign designs. |
| **Entry point** | [`SKILL.md`](SKILL.md) - orchestrator with per-signal routing and core reference index. |

## Resource groups

| Folder | Holds |
|---|---|
| `resources/core/` | Six core signals, scoring framework, 137-trigger taxonomy |
| `resources/detection/` | 30-trigger quick reference, Clay credit costs, tool setup guides |
| `resources/plays/` | 11 executable GTM plays and Clay job-change tracking |
| `resources/signals/` | Per-signal deep dives (one file per signal type) |
