# Winning Words and Phrases

**What this file is:** the language the best GTM operators on LinkedIn actually use, so your posts sound like the people who win, not the average.

**What it isn't:** a swipe file of full sentences to copy.

The numbers below are the **share of winning posts that use the word**, not raw counts. Raw counts reward filler (the word "you" shows up thousands of times and tells you nothing), and counts from different datasets can't be compared. Share-of-winning-posts is honest, and it's the same forcing function: if 65% of winning posts say "claude," you probably should too. It's a snapshot, so re-check it as the space shifts.

## 1. Words to use

The vocabulary that shows up most in winning posts:

| Word | In winning posts |
|---|---|
| ai | 67% |
| claude | 65% |
| code | 52% |
| gtm | 47% |
| linkedin | 46% |
| data | 45% |
| outbound | 39% |
| tools | 32% |
| build / built | 31% |

Verbs that show up in the winning posts: run (37%), built (34%), use (32%), build (31%), building (29%), find (19%), send (18%), scale (16%), start (15%), reply (13%), write (13%).

Tool names are part of the language. The best operators name the exact tool: instantly, apollo, clay, rb2b, hubspot.

**Add your niche vocabulary.** On top of the core words, layer the terms specific to your focus. For a signal-based, ICP-led niche, that means words like **signal(s), icp, and hubspot**. The specific tools and terms you name are what mark you as an operator rather than a generalist.

## 2. Words to avoid

Two lists. First, the editorial ban, because these read as corporate-marketer filler:

leverage, unlock, game-changer, synergy, align, deep dive, revolutionize, paradigm, disrupt, empower, holistic, robust, seamless, elevate.

Second, words that show up in weaker posts but rarely in the winners:

| Word | Why it's weak |
|---|---|
| teams | too generic |
| problem | vague, no specific stakes |
| message / reps / means | filler in this niche |
| qualified / founders | abstract audience labels |
| everyone | broad, low-signal |

Be concrete and specific. Don't lean on a vague abstraction or your own brand name to carry a post.

## 3. Phrases

| Phrase | Winning posts |
|---|---|
| claude code | 193 (the #1 phrase by far) |
| cold email | 32 |
| tech stack | 28 |
| tool names (instantly ai, apollo io, linkedin ads) | 24 to 49 |
| comment-gate CTA ("comment X and I'll send it", "dm me") | common closer |
| builder voice ("we build", "the system") | agency and operator tone |

Copy the pattern and fill it with your own specifics. Never reuse a literal competitor name or link. Don't use these exact words; these are just patterns in the GTM space. The conclusion and pattern are what you want to reuse or decide when not to use.

## 4. Sentences

| Trait | Winning posts | Rule |
|---|---|---|
| Line length | median 7 words | short, scannable, not essays |
| Arrows (the ↳ character) | ~48% | use them to break lists into rows |
| Numbered steps | ~46% | Step 1 / 1, 2, 3 walkthroughs |
| Emojis | ~39% | sparingly, 0 to 2 |
| P.S. close | common | keep a P.S. line |
