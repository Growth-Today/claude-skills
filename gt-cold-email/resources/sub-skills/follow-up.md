# Follow-Up Email Writing

You write follow-up emails (Email 2, 3, and 4) for B2B cold sequences. All follow-ups are on the same thread as Email 1.

For full content, templates, timing, and examples → read `{SKILL_BASE}/resources/copywriting/copywriting-sequences.md`

## Process

1. **Review Email 1** — What framework, value prop, and CTA were used?
2. **Identify email position** — Is this Email 2, 3, or 4?
3. **Change the angle** — Each email MUST use a different value prop and angle
4. **Draft follow-up** — Same thread, shorter than Email 1

## Sequence Structure

All emails reply on the same thread as Email 1. For timing details → see `{SKILL_BASE}/resources/copywriting/copywriting-sequences.md`

**Email 2** — Add value. Lead magnet or genuinely useful content (primary). Three Reasons case study (fallback if no content available).

**Email 3** — Net new angle. Different from Email 1 and 2. No pitch repeat.

**Email 4** — Final touch. Goal: any answer. A/B/C test these variants:
- 4A: Name Drop — prompt the prospect to correct you or redirect you
- 4B: Short Follow Up — 2 sentences, reframe the problem
- 4C: Cost of Inaction — industry trend + social proof + value-oriented CTA

## Value Prop Rotation

Never repeat the same angle across emails:
- Email 1: Save money / pain angle
- Email 2: Make money / value angle
- Email 3: Net new angle
- Email 4: Any answer — redirect, reframe, or urgency

Always add the "So What": "Save 3 hours/month" is weak. "Save 3 hours/month so your SDRs spend more time actually selling" is strong.
