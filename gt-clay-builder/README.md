# Clay Builder

Clay enrichment and workflow-automation skill: an orchestrator that routes each build to the right sub-skill and enforces credit-efficient, waterfall-first patterns.

| | |
|---|---|
| **What it does** | Builds enrichment workflows - email and phone waterfalls, company and people enrichment, Claygent research, Clayscript formulas, conditional logic, lead scoring, CRM sync - and debugs tables that waste credits. |
| **Use it when** | The request is about Clay tables, waterfall enrichment, credits/pricing, Claygent, Clayscript, finding emails or phones, lead scoring, CRM sync, or Clay debugging. Not for general CRM questions without Clay or non-Clay enrichment platforms. |
| **Outputs** | Table and column designs, waterfall setups, ready-to-use formulas and Claygent prompts, and credit-cost estimates with optimizations. |
| **Entry point** | [`SKILL.md`](SKILL.md) - orchestrator with sub-skill routing and the seven universal enrichment principles. |
